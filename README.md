# Hi, I'm Denis

Senior Unity developer in Tenerife, Spain. I've been making games for 14+ years and using Unity since v4, with C# as my main language. By day I work on live mobile games at NanoReality Games. The rest of the time I build Unity tools and an indie game.

## What I build

- **Unity tools**: editor windows, GraphView node editors and UPM packages that keep gameplay code data-driven and easy to work with.
- **AI / LLM in Unity**: an in-editor assistant that runs editor actions, MCP bridges so agents like Cursor and Codex can drive the Editor, and generative-AI node graphs.
- **Games**: gameplay and systems architecture, game feel, URP shaders and mobile performance.
